# OmniCalc 📱⚡

**OmniCalc** is a 100% ad-free, privacy-first, fully customized daily needs utility and financial calculation suite built natively for Android using Kotlin and Jetpack Compose.

It replaces multiple bloated, ad-ridden single-purpose apps with one streamlined, offline-first personal dashboard designed for speed, security, and daily efficiency.

---

## 🌟 Why OmniCalc?

* **Zero Ads, Zero Trackers**: No banner ads, no popups, no video interstitials, and no third-party tracking SDKs.
* **100% Offline-First**: All your data, calculation history, and financial ledgers stay securely on your device.
* **Optimized Battery & Performance**: Lightweight architecture built with native Jetpack Compose with zero background network drain.
* **Modular & Customizable**: Easily adapt themes (including true AMOLED Dark Mode) and manage your dashboard to fit your exact daily workflow.

---

## 🚀 Key Features

### 1. Loan & EMI Tracker
* **Multi-Category Tracking**: Manage Home, Car, Personal, and Mobile/Gadget loans.
* **Due Date Reminders**: Set specific monthly repayment days (1–31) with on-device local notifications so you never miss an EMI.
* **Instant Amortization**: Automatically calculate monthly installments, total interest payable, and final payoff costs.
* **Bank Deduction Accounts**: Track which bank account deducts which loan to maintain a clean monthly cash-flow overview.

### 2. Comprehensive Financial Ledger
* **Debt Tracker**: Bilateral debt logging to record money borrowed or lent to friends and contacts, complete with settlement status.
* **Smart Bill Splitter**: Group expense sharing with split-share calculations, receipt breakdown, and integrated UPI payment triggers.
* **Investment & Interest Calculators**: Dedicated scenario tools for Simple Interest, Compound Interest, loan prepayments, and return forecasts.
* **Visual Insights**: Clean, reactive charts (Donut breakdown and Growth Line charts) for fast financial reviews.

### 3. All-in-One Daily Utilities
* **Dual Calculation Modes**: Instant switching between clean standard arithmetic and full scientific evaluations.
* **Calculation History**: Saved calculation logs with one-tap favorites and recall.
* **Smart Converters**: Fast everyday conversions for Units, Currency, Age, and Calendar date differences without needing a web browser.

### 4. Privacy & Local Data Portability
* **No Cloud Dependency**: Runs entirely offline without requiring an account or internet connection.
* **Complete Backup & Restore**: Export and import your entire database locally via standard JSON backup files anytime.

---

## 🛠️ Technical Stack

* **Language**: Kotlin
* **UI Framework**: Jetpack Compose (Material 3)
* **Architecture**: Clean Architecture / MVVM with Repository Pattern
* **Local Storage**: Room Database (SQLite)
* **Asynchronous Flow**: Kotlin Coroutines & StateFlow
* **Notifications**: Local Android NotificationManager & AlarmManager
